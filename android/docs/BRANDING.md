# Canonical Android Branding

The only approved Critter Extraction app icon is:

`live/assets/branding/icon.svg`

SHA-256:

`9755289ef076355c7275f84a79fe31afc2d2f970f6d5710369c643317684d2a0`

This is the brown-and-mint puppy artwork shown in the browser game's top-left brand area and in
the repository README. Android renders the SVG directly in the native boot screen and top-left
header. The launcher resources use a 1024×1024 PNG exported directly from the same SVG because
Android launchers do not consume SVG files as launcher resources.

Do not replace it with the HTG studio mark, a generic paw, a text monogram, or regenerated art.
If the canonical SVG is intentionally updated, regenerate the PNG and update the branding
contract in the same reviewed change.
