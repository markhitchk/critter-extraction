## Release staging area

The Prerelease channel is used to assemble and review upcoming Critter Extraction improvements before they are promoted to LIVE. It includes the project’s authored 3D asset integration work and can be used to inspect release-candidate gameplay changes.

| Focus | Prerelease goal |
|:--|:--|
| **Gameplay** | Confirm new features work together as a complete extraction loop |
| **Assets** | Validate authored GLB models, fallbacks, scale, materials, and runtime placement |
| **Performance** | Measure startup, rendering, memory, and responsive behavior |
| **Compatibility** | Verify profiles, saves, room links, portable builds, and current browsers |
| **Release quality** | Identify blockers before changes move into LIVE |

## Authored asset inspection

This channel contains imported CC0 models and a browser model gallery used to inspect supported assets and animation metadata.

- **[Open the model gallery](model-gallery.html)**
- **[Read third-party asset licenses](assets/models/third_party/LICENSES.md)**

Procedural assets can remain as load-failure fallbacks. Imported or rigged models are not considered gameplay-complete until they are correctly connected, animated, scaled, and validated inside a real match.

## Prerelease checklist

1. Test a clean first visit and an existing profile.
2. Verify Solo, Co-op, and VS Arena entry flows.
3. Check camera alignment, aiming, AI, loot, objectives, and extraction.
4. Inspect inventory, stash, loadout, Trading Post, and profile dialogs at several viewport sizes.
5. Verify authored assets and their fallback behavior.
6. Confirm no private profile, room, or token data enters reports.
7. Compare behavior against LIVE before recommending promotion.
