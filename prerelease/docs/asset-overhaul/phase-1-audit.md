# Critter Extraction — High-End 3D Asset Overhaul Audit

Status: Phase 1 foundation

Primary visual target:

- `assets/loading/gameplay-reference.webp`
- `assets/loading/cinematic-gameplay-fullhd.webp`

This audit records the current runtime asset contract before high-end 3D replacements are introduced. It intentionally does not claim that planned GLB models or PBR texture sets already exist.

## Current Runtime Architecture

The game currently starts from `index.html`, loads `core/rendering/model-library.js`, and then loads `core/loader/game-loader.js`, which starts the canonical game implementation in `core/game/game-core.js`.

Current visible assets are a mixture of:

- Procedural geometry generated by the game renderer
- SVG character artwork under `assets/characters/`
- SVG weapon artwork under `assets/weapons/`
- SVG item artwork under `assets/items/`
- WebP loading and reference artwork under `assets/loading/`
- Runtime vendor libraries under `assets/vendor/`

The current `core/rendering/model-library.js` is a procedural catalog. It defines the enemy roster, region asset packs, shared landmarks, character parts, weapon IDs, and combat hit zones. It does not yet load game-ready GLB character, weapon, foliage, terrain, or structure assets.

## Runtime Contract

New runtime assets must use repository-relative paths and browser-ready formats:

- Models: `.glb` preferred; `.gltf` permitted when external resources are packaged correctly
- Textures: `.webp`, `.png`, `.ktx2`, or Basis-compatible compressed assets
- Source files: may be retained outside runtime loading paths when licensing and repository size permit
- Up axis: Y-up for glTF runtime assets
- Units: meters
- Character origin: centered between the feet at ground level
- Weapon origin: receiver center with explicit grip, support-grip, muzzle, sight, and magazine nodes
- Environment origin: practical placement pivot at ground contact

## Performance Contract

Every repeated environment family must support at least one of:

- GPU instancing
- Shared geometry and materials
- LOD switching
- Distance culling
- Impostors for distant vegetation

The vertical slice will be rejected if it only looks correct in an isolated render but cannot run inside the browser game.

## Compatibility Requirements

The overhaul must not intentionally alter:

- Save schema or account data
- Solo, co-op, or PvP rules
- Friendly-fire behavior
- Room codes and join links
- AI combat behavior
- Inventory and stash data
- Quests and extraction rules
- Hit detection or damage values
- Existing fallback UI icons until replacements are validated

## Current Gaps

The repository does not yet contain a complete high-end authored asset library matching the gameplay reference. In particular, the current pipeline lacks a central 3D asset manifest, formal LOD paths, attachment metadata, texture-set declarations, collision declarations, and automated checks for planned/active GLB assets.

The files introduced with this phase establish those contracts without falsely marking unfinished assets as production-ready.
